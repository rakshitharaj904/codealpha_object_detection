Object Detection and Tracking
A Python-based Object Detection and Tracking project developed as part of the CodeAlpha AI Internship – Task 4.
Project Overview
This project uses a pretrained YOLO model to detect and track objects in a video.
Features
Real-time object detection
Object tracking
Pretrained YOLO model
Video processing
Detection results saved automatically
Technologies Used
Python
YOLO
Ultralytics
OpenCV
How It Works
Load a pretrained YOLO model.
Provide a video as input.
Detect objects in each video frame.
Track detected objects across frames.
Save the processed output.
How to Run
Install Ultralytics:
pip install ultralytics
